# AI Graphics Editor Client — Phase 5

React + Vite + Redux Toolkit + React-Konva + Tailwind CSS.

## Phase 5 additions

- Asset library panel
- Upload persistent image assets
- Asset thumbnails and metadata
- Insert assets into the canvas
- Replace the selected image layer from the asset library
- Delete unused assets
- Existing image upload button remains supported

## Run

```bash
npm install
npm run dev
```
